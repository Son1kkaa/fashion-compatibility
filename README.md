## Опис проєкту

Веб-застосунок для автоматичного оцінювання візуальної сумісності елементів одягу на основі сіамської нейронної мережі з архітектурою ResNet50. Система аналізує візуальні характеристики елементів гардероба (колір, текстуру, фасон) та визначає рівень їхньої стилістичної сумісності.

### Можливості системи

- **Попарний аналіз** — завантажте два елементи одягу та отримайте оцінку сумісності у відсотках з текстовою рекомендацією
- **Top-K рекомендації** — завантажте один елемент, оберіть категорію пошуку та отримайте найбільш сумісні елементи з бази гардероба

### Метрики моделі (тестова вибірка, 6 000 пар)

| Метрика | Значення |
|---------|----------|
| Accuracy | 88.45% |
| Precision | 85.86% |
| Recall | 92.07% |
| F1-score | 88.85% |
| AUC | 0.9432 |

## Встановлення та запуск

### 1. Клонування репозиторію
```bash
git clone https://github.com/YOUR_USERNAME/fashion-compatibility.git
cd fashion-compatibility
```

### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3. Підготовка бази гардероба
Додайте зображення одягу у папки:
```
static/wardrobe/tops/       ← футболки, светри, блузки
static/wardrobe/bottoms/    ← штани, джинси, спідниці
static/wardrobe/shoes/      ← взуття
```

### 4. Запуск
```bash
python app.py
```
Індексація бази гардероба виконується автоматично.

### 5. Використання
Відкрийте у браузері:
```
http://127.0.0.1:5000/
```
На головній сторінці доступна навігація між двома режимами:
- **Порівняння пари** — оцінка сумісності двох елементів одягу
- **Top-K рекомендації** — пошук найбільш сумісних елементів з бази

## Навчання моделі

Навчання виконувалось у Google Colaboratory (GPU: NVIDIA Tesla T4).

**Датасет:** Polyvore Outfits (nondisjoint), 47 000 пар

**Гіперпараметри:**

| Параметр | Значення |
|----------|----------|
| Epochs | 5 |
| Batch size | 32 |
| Optimizer | AdamW (weight_decay=0.01) |
| LR backbone | 3 × 10⁻⁶ |
| LR head | 1 × 10⁻⁴ |
| Dropout | 0.4 / 0.2 |
| Loss | BCEWithLogitsLoss |
